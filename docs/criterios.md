# Criterios de Clasificación de Recursos Académicos

Para mantener una catalogación estandarizada, cada recurso académico ingresado al sistema se clasifica según cuatro criterios principales:

1. **Tipo de Recurso:** Practica

2. **Tema / Área de Conocimiento:** ICO

3. **Nivel Académico:** Universidad

4. **Autor o Fuente:** David Salvador Jaramillo Ayala


## Nuevos Criterios de Clasificación

* Nivel de Accesibilidad (Open Access vs. Suscripción):** Clasifica si el recurso permite la lectura y descarga gratuita de manera libre o si requiere credenciales institucionales o pago de licencia.
* **Tipo de Contenido / Formato de Publicación:** Distingue si el recurso se trata de un artículo revisado por pares (*peer-reviewed*), un preprint, una tesis doctoral, un libro o una memoria de conferencia.
